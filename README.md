# BizAI Hub — Flutter

ИИ-приёмка заказов из Instagram, Telegram и WhatsApp для малого бизнеса Тараза. Одно приложение на Flutter работает на телефоне (Android, iPhone), на ПК (Windows, macOS, Linux) и в браузере.

Демо-бизнес — кофейня-пекарня «Дәмді Кофе». Интерфейс переключается между русским и казахским (RU / KZ в шапке), есть светлая и тёмная тема.

## Что внутри

- **Дашборд**: выручка за сегодня в ₸, сэкономленные часы сотрудников, конверсия из диалога в оплату, число заявок, обработанных ИИ. Ниже выручка по часам, статусы заказов, каналы и лента событий.
- **AI Inbox**: диалоги со статусами «Новый лид», «Ожидает оплаты Kaspi», «Оплачен», «Передан курьеру». В чате видно расшифровку голосового, товар, распознанный на фото, адрес по геоточке, шаги разбора ИИ и его ответ на языке клиента. Справа карточка заказа: позиции, сумма, адрес в Таразе, телефон и кнопки следующего шага.
- **ИИ-аналитика**: экономия на зарплате, рекомендации владельцу, прогноз остатков, причины отказов, спрос по часам.
- **Симулятор**: кнопка «Симулировать обращение» (на телефоне — «Демо» в нижнем меню). Клиент пишет на русском или казахском, ИИ разбирает сообщение, выставляет счёт Kaspi, через несколько секунд приходит чек, и выручка растёт. «Автопоток» присылает новое обращение каждые 7 секунд.

## Что нужно установить

- Flutter 3.24 или новее (канал stable): https://docs.flutter.dev/get-started/install
- Для Android-телефона: Android Studio (Android SDK) и телефон с включённой отладкой по USB.
- Для iPhone: Mac с Xcode.
- Для Windows-приложения: Visual Studio 2022 с компонентом «Разработка классических приложений на C++».
- Для браузера: Google Chrome.

Проверить установку: `flutter doctor`.

## Первый запуск

В архиве только код приложения. Папки платформ (android, ios, windows и т. д.) Flutter создаёт сам — для этого есть скрипт.

**Windows:**
```powershell
cd bizai_hub
powershell -ExecutionPolicy Bypass -File setup.ps1
```

**macOS / Linux:**
```bash
cd bizai_hub
bash setup.sh
```

Скрипт выполняет `flutter create .`, разрешает приложению выход в интернет на Android и macOS и скачивает зависимости.

## Запуск

| Где | Команда |
|---|---|
| Android-телефон по USB | `flutter run` |
| Файл APK для установки на телефон | `flutter build apk --release` → `build/app/outputs/flutter-apk/app-release.apk` |
| iPhone (нужен Mac) | `flutter run -d ios` |
| ПК с Windows | `flutter run -d windows`, готовая программа: `flutter build windows` → `build/windows/x64/runner/Release/` |
| ПК с macOS / Linux | `flutter run -d macos` / `flutter run -d linux` |
| Браузер на ПК | `flutter run -d chrome` |
| Сайт для любого ПК и телефона | `flutter build web --release` → загрузите папку `build/web` на любой хостинг (GitHub Pages, Netlify, Vercel) |

APK можно отправить в Telegram или WhatsApp и установить на любой Android: телефон попросит разрешить установку из этого источника.

## Живой ИИ (необязательно)

Встроенный разбор работает без интернета: понимает товары и количество на русском и казахском, улицы и микрорайоны Тараза, телефоны, время и самовывоз.

Чтобы свои сообщения (кнопка «Своё сообщение» в симуляторе) разбирал Claude, нужен ключ Claude API. Его можно ввести в настройках приложения (значок с ползунками в шапке) или передать при запуске:

```bash
flutter run --dart-define=CLAUDE_API_KEY=sk-ant-...
```

Модель по умолчанию — `claude-haiku-5-5`, её можно сменить в настройках. Ключ хранится только в памяти приложения. Встраивать ключ в приложение, которое раздаёте другим людям, нельзя: его можно извлечь. Для демо на хакатоне этого достаточно, для продакшена запросы к Claude нужно вести через свой сервер.

## Структура

```
lib/
  main.dart               запуск приложения, темы
  theme.dart              цвета и шрифты
  engine/                 ИИ-движок без зависимостей от интерфейса
    catalog.dart          меню, улицы и микрорайоны Тараза, демо-сообщения
    parser.dart           разбор сообщения RU/KZ, расчёт заказа и доставки
    replies.dart          ответы ИИ клиенту
    claude_client.dart    необязательный разбор через Claude API
  state/
    app_state.dart        диалоги, метрики, сценарии симулятора, автопоток
    i18n.dart             тексты интерфейса RU/KZ
    models.dart           модели данных
  ui/
    shell.dart            адаптивная оболочка: боковое меню на ПК, нижнее на телефоне
    dashboard.dart        дашборд
    inbox.dart            AI Inbox: список, чат, карточка заказа
    analytics.dart        ИИ-аналитика
    charts.dart           график по часам, тепловая карта, иллюстрации
    sheets.dart           симулятор, своё сообщение, настройки
assets/fonts/             Onest, Unbounded, JetBrains Mono (лицензия OFL)
```

## Сценарий демо на хакатоне (2 минуты)

1. Откройте дашборд и нажмите «Симулировать обращение». В углу появится уведомление: ИИ разбирает сообщение, выставляет счёт, клиент оплачивает, выручка растёт.
2. Откройте AI Inbox и покажите голосовое на казахском или фото торта: ИИ распознал товар, адрес и телефон, карточка заказа заполнилась сама.
3. Включите «Автопоток» и перейдите в ИИ-аналитику: остатки на складе и спрос по часам меняются с каждым заказом.
